Wellness Wave - NGO Wellness Platform

Project Overview
Wellness Wave is a multi-page website developed as a university assignment to support a wellness-focused NGO. The platform is designed to demonstrate compassion and advocacy for the well-being of both humans and animals, providing community guidelines and raising awareness for health and welfare.
Tech Stack
* HTML5: Used to build the core structure across multiple pages including Home, About Us, Our Services, Donation, and Contact Us.
* CSS3: Custom styling for a clean, responsive layout with dedicated navigation bars and interactive call-to-action boxes.
* JavaScript: Implements functional form validation for volunteer sign-ups and donation processing.
Key Features
* Dynamic Landing Page: Features summaries of all site sections with clear call-to-actions to engage users immediately.
* Donation System: A dedicated page allowing users to select donation types and amounts, featuring real-time feedback via JavaScript.
* Volunteer Integration: A "Become a Volunteer" form on the Contact page to gather community support.
* Resource Center: An "Our Services" section highlighting programs like Health Education and Mental Health Support.
* Responsive Design: Includes wireframes and mockups optimized for both desktop and small screen viewing.
 Project Structure
* index.html: The main entry point.
* about-us.html: Detailed information about the organization's founders and goals.
* our-services.html: Overview of the health and education programs offered.
* Donation.html: Interface for financial contributions to support the cause.
* Contact-us.html: Communication hub for general inquiries and volunteer registration.
* report.html: Comprehensive project documentation including design wireframes and credits.
* styles.css: Central stylesheet managing the visual identity of the entire platform.
* java.js: Script handling form interactions and user alerts.
  
Context
This project was completed as an assignment to showcase foundational web development skills and the ability to design for a non-profit social cause.
